# 结果：B 轴（c=32 短并发吞吐）漂移统计与归因 — 2026-11-10 ～ 11-27

> 面向外部分享：同配置下 c=32 五窗吞吐为什么从 ~100 漂到 ~197 tok/s；给出历史读数、五类漂移的次数与场景、可操作的实验判据。**数字全部来自本项目实测**（run_id 可查），推测处已标注。

## 0. 一句话结论

同配置（K5·BS32·MNS32·MMBT8192·priority·multistream=true）的 B 轴历史读数 **99–197 tok/s**，稳态带 **156–172**；漂移不是单一噪声，而是**五类可辨识现象**：① 冷启（每次重启，W1 −50~−62%）② 长跑/堆积衰减（−12~−38%）③ 异常高点（+5~+20%）④ 降级态（profiler/配置，−12~−27%）⑤ 时段负载（−8~−20%，主要在 F 轴）。**单次 5 窗中位数不足以判 A/B**：须近窗 CTRL + 离群剔除（|x−中位|>3·MAD）+ 二次独立五窗。

## 4. 关键案例：2026-11-26 A-1 平衡调度（漂移如何制造假判负）

时间线（同指纹族、同协议、8 窗预热）：

- 21:27–21:32 **177.83**（CTRL，MAD 1.23%）← **异常高点**
- 21:59–22:04 A-1（balance 键）**158.15**
- 22:58–23:04 删键回滚 **156.02**
- 09:05–09:10 过夜复测 **157.13**（MAD 1.62%）

若只用 21:30 CTRL：A-1 = **−11.1%** ⇒ 会判「平衡调度负收益」。
加上回滚/过夜两点：A-1 vs 稳态带（156–158）= **+0.7~+1.4%** ⇒ **无可判 ≥10% 效应**；−11.1% 是异常高点的假象。
**教训**：单点 CTRL 不可作分母；至少「改前/改后/复测」三点同带才判。

## 5. 对实验方法的要求（可直接复用）

1. **重启后 16 窗预热**（8 窗不够）——全丢弃后再测。
2. **近窗 CTRL**：对照组与实验组相隔 ≤10–15 min，或改前/改后各测一次。
3. **二次独立五窗**：同配置连续两轮五窗一致（MAD<10% 且中位差<5%）才允许作对照。
4. **离群剔除**：|x−中位|>3·MAD 的单窗/单点单列，不进中位（或标注）。
5. **组间冷却**：同一会话内两组之间 ≥30 min 空载（A2→A2c 证据：空闲 1 h 回升 +2%）。
6. **不跨指纹/跨 MNS 横比**；跨日比较必须带「时段 + 预热形态」说明。
7. **报告附逐窗分布**：中位数会掩盖双态振荡（11-16 WATCH 案例：同轮 171.10↔113.07）。
